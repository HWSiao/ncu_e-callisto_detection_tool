# NCU_e-CALLISTO_Detection_Tool
Interactive FITS Reader, RFI Processing &amp; YOLO Label Generator (640x640 Format)
# How to Use
Step 1. Upload TAIWAN-NCU e-CALLISTO FITS files.
(Max 4 continuous files per batch)
![https://hwsiao.github.io/ncu_e-callisto_detection_tool/img/Guideline01.png](https://hwsiao.github.io/ncu_e-callisto_detection_tool/img/Guideline01.png)
Step 2. Adjust the image settings to check SRB signal clearly.
![https://hwsiao.github.io/ncu_e-callisto_detection_tool/img/Guideline02.png](https://hwsiao.github.io/ncu_e-callisto_detection_tool/img/Guideline02.png)

Step 3. Click on the categories which you would to mark.
(0: RFI Interference, 1: Type I Burst, 2: Type II Burst, 3: Type III Burst, 4: Type IV Burst, 5: Type V Burst, 6: Other solar radio signal)
![https://hwsiao.github.io/ncu_e-callisto_detection_tool/img/Guideline03.png](https://hwsiao.github.io/ncu_e-callisto_detection_tool/img/Guideline03.png)

Step 4. Circle the signal. 
Step 5. The box information are shown with YOLO format.
Step 6. Click on the “Export YOLO Package (.zip)” button to download the marked results.  
![https://hwsiao.github.io/ncu_e-callisto_detection_tool/img/Guideline04.png](https://hwsiao.github.io/ncu_e-callisto_detection_tool/img/Guideline04.png)
![https://hwsiao.github.io/ncu_e-callisto_detection_tool/img/Guideline05.png](https://hwsiao.github.io/ncu_e-callisto_detection_tool/img/Guideline05.png)
